# jinyang-portfolio

杨金的个人作品集网站，记录我在 AI 产品、内容运营、工作流设计与建筑设计中的实践。

每个案例按照“用户问题与背景 → 我做了什么 → 最终效果”展开，公开仓库不包含个人简历、私人照片或联系方式。

## Featured projects

- [Image Prompt](https://github.com/jinyang-simplify/image-prompt) — 将参考图片转换为结构化中文生图提示词。
- [稿定简历](https://github.com/jinyang-simplify/gaoding-resume) — 基于岗位要求和真实证据的可解释 AI 简历优化产品。
- [走马岭数字预运营系统](https://github.com/jinyang-simplify/zoumaling-digital-operations) — 面向乡村文旅的游客体验、路线规划与运营管理系统。
- [AI.Simplify Skills](https://github.com/jinyang-simplify/ai-simplify-skills) — 面向设计与内容场景的可安装 AI Skill 合集。
